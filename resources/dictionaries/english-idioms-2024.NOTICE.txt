Data name: English Idioms and Expressions
Data format: generated TSV (phrase<TAB>meaning), gzip-compressed

This file is a format conversion of the idioms.csv file from the
baiango/english_idioms repository. The upstream repository describes this as
a list of more than 500 English idioms; the source revision used here has
1,024 usable entries. It is a supplemental phrase source, not a complete or
editorially authoritative dictionary. The upstream README notes that some
entries may be incorrect or have both literal and figurative meanings.

The generated pack keeps duplicate phrase meanings when the source provides
different definitions. The conversion filters rows without a phrase or
meaning, rejects embedded control characters or unmatched quotes, and removes
an obvious unmatched terminal quote from otherwise valid upstream CSV rows.

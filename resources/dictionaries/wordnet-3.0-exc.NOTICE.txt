Kalam bundled dictionary notice — WordNet exception lists
==========================================================

Data name: Kalam WordNet 3.0 morphological exception lists
Data format: gzip-compressed WordNet .exc files, one entry per line:
surface-form<whitespace>lemma [lemma ...]  (lowercase)

These four files are the Princeton WordNet 3.0 morphological exception
lists (noun.exc, verb.exc, adj.exc, adv.exc). They map irregular surface
forms to their lemmas (went -> go, mice -> mouse, better -> good) and are
consulted by the reader's dictionary lookup before the regular suffix
rules, so irregulars resolve to a headword instead of a dead end.

Upstream source:
Princeton WordNet 3.0, Princeton University — the .exc files ship in the
official WordNet 3.0 distribution (wordnet.princeton.edu). The copies in
this directory were obtained from the NLTK wordnet corpus mirror
(github.com/nltk/nltk_data, packages/corpora/wordnet.zip), which packages
the unmodified Princeton WordNet 3.0 dict files alongside the WordNet
licence text.
